O que é uma função

Um pedaço de código com nome, que você escreve uma vez e usa quantas vezes quiser. Como uma receita: você guarda a receita e depois só diz o nome dela.

Anatomia

def nome_da_funcao(parametro):
    ...corpo, sempre recuado...
    return resultado

resultado = nome_da_funcao(valor)
Parâmetro e argumento não são a mesma coisa

Parâmetro é o que está entre parênteses na hora de definir a função. Ele cria um pedacinho de memória que nasce quando a função é definida e só existe dentro da função. Fora dela, esse nome não vale nada.

Argumento é o valor de verdade que você coloca entre parênteses na hora de chamar a função. 

def dobro(numero):      numero é o PARÂMETRO — só existe aqui dentro
    return numero * 2

dobro(7)                7 é o ARGUMENTO — é o que entra no lugar

Função que devolve verdadeiro ou falso

Uma função pode devolver True ou False. Serve para responder pergunta de sim ou não.

def alguma_pergunta(valor):
    if valor > 10:
        return True
    return False

Decidir entre vários casos

if condicao_1:
    ...
elif condicao_2:
    ...
else:
    ...

As condições são testadas de cima para baixo. A primeira que der certo é a que vale, e o resto nem é olhado.

Juntar condições

if a >= 60 and b == "não":     as duas precisam ser verdadeiras
if a >= 60 or b == "não":      basta uma ser verdadeira

Passar por todos os itens de uma lista

soma = 0
for item in lista:
    soma = soma + item

O acumulador (soma) é criado antes do for, nunca dentro.
