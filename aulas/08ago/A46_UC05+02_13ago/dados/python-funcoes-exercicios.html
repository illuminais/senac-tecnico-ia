1. Escreva def saudacao(nome) que devolva "Olá, Rex" quando receber "Rex".
2. Escreva def dobro(numero) que devolva o número multiplicado por 2. Depois escreva, embaixo, a linha que chama a função com o valor 7 e guarda o resultado.
3. Escreva def media(a, b) que devolva a média dos dois números recebidos.
4. Escreva def passou_do_prazo(dias_no_abrigo, limite) que devolva True quando dias_no_abrigo for maior que limite, e False quando não for.
Atenção: aqui o número de comparação não é fixo — ele chega junto, como segundo parâmetro.
5. Escreva def levar_guarda_chuva(chance_de_chuva, vai_de_carro), onde chance_de_chuva é um número de 0 a 100 e vai_de_carro é o texto "sim" ou "não". A função devolve:
True se a chance for 90 ou mais — nesse caso vai chover forte, carro ou não;
True se a chance for 60 ou mais e a pessoa não for de carro;
False em qualquer outro caso.
6. Escreva, embaixo da função do exercício 5, as linhas que: perguntam ao usuário a chance de chuva, perguntam se ele vai de carro, chamam a função e mostram a resposta na tela.
Cuidado com o tipo do que vem do input.
7. Escreva def taxa_de_adocao(adotados, total) que devolva a porcentagem de adotados. Se total for zero, a função deve devolver zero em vez de tentar a conta.
8. Escreva def soma_dias(lista_de_dias) que receba uma lista de números e devolva a soma de todos eles. 
Exemplo: soma_dias([10, 210, 22])  devolve  242
9. Escreva def contar_grandes(portes) que receba uma lista de textos e devolva quantos deles são "grande". 
Exemplo: contar_grandes(["grande", "pequeno", "grande"])  devolve  2
10. Escreva def ficha(animal) que receba um dicionário e devolva o texto no formato "Rex — porte grande". 
Exemplo: ficha({"nome": "Rex", "porte": "grande"})
11. Escreva def contar_por_porte(animais, porte_procurado) que receba uma lista de dicionários e devolva quantos animais têm o porte procurado. 
animais = [{"nome": "Rex", "porte": "grande"},
           {"nome": "Mel", "porte": "pequeno"},
           {"nome": "Max", "porte": "grande"}]

contar_por_porte(animais, "grande")  devolve  2
