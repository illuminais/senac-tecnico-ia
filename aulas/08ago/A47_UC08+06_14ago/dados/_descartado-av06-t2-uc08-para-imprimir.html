1.1 No banco de dados, um usuário é: ☐ a) uma conta criada dentro do banco, com permissões próprias ☐ b) a pessoa física que senta na frente do computador ☐ c) o programa que abre a conexão com o banco ☐ d) o dono da empresa que pagou pelo sistema
1.2 O princípio do menor privilégio diz que: ☐ a) o banco deve ter o menor número possível de contas criadas ☐ b) quem tem menos tempo de casa deve receber menos acesso ☐ c) cada conta recebe só o que precisa para o próprio trabalho ☐ d) as permissões devem ser revisadas pelo menos uma vez por ano
1.3 GRANT SELECT ON abrigo.animais TO 'ana'@'localhost'; permite que a Ana: ☐ a) apague linhas da tabela animais ☐ b) crie a estrutura da tabela animais ☐ c) dê permissão de leitura para outras contas ☐ d) leia as linhas da tabela animais
1.4 Para tirar uma permissão que já tinha sido dada, usa-se: ☐ a) DELETE ☐ b) REVOKE ☐ c) DROP USER ☐ d) ALTER USER
1.5 O sqliteonline.com não tem GRANT nem REVOKE porque: ☐ a) é a versão gratuita, e esses comandos são só da versão paga ☐ b) esses comandos saíram das versões mais novas da linguagem SQL ☐ c) o SQLite é um banco de arquivo único, sem servidor e sem contas ☐ d) só o administrador do site tem autorização para usar esses comandos
1.6 A tabela adotantes guarda CPF e endereço. O acesso a ela deve ser: ☐ a) liberado para todos, afinal é tudo a mesma instituição ☐ b) bloqueado para todo mundo, inclusive para a coordenação ☐ c) liberado apenas para quem souber escrever SQL direito ☐ d) restrito a quem precisa desses dados para trabalhar
