As 4 etapas de uma consulta com grupos

Responda as 4, nesta ordem, antes de escrever a consulta.

1

Filtrar linhas · WHERE
Quais linhas entram na conta?

2

Definir o grupo · GROUP BY
O resultado tem uma linha para cada o quê?

3

Calcular o resumo · SUM dentro do SELECT
O que calcular em cada grupo?

4

Filtrar grupos · comando de 01/10:
Quais grupos ficam no resultado?

SELECT macrorregional, SUM(casos) AS total  ← 3
FROM casos_dengue
WHERE ano = 2025 AND mes = 3                ← 1
GROUP BY macrorregional                     ← 2
ORDER BY total DESC;

Ordem em que o banco executa: FROM → WHERE → GROUP BY → SELECT → ORDER BY → LIMIT
